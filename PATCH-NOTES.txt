NahIDWin v0.8 source update

- MCM removed all image loading and uses the stable SkyUI/TrueHUD reset pattern: exactly 3 pages, TOP_TO_BOTTOM, SetCursorPosition(0); GetVersion bumped to 8 so old saved MCM state refreshes.
- Papyrus compiler stub declares SetCursorPosition.
- Parry input recognizes Skyrim's blockStart/blockStop and leftAttack controls, reads button value as float, checks release timer, and logs relevant input events plus successful armed windows.
- Each player hit consumes one parry attempt. The short damage follow-through applies only to the attacker that was parried, not every incoming attacker.
- Preserved the environmental hit filter, disabled experimental custom HUD bars by default, and included the supplied LE camera/stagger overrides.
- No MCM DDS images are included or copied by the workflow.

Validation: static checks performed. DLL and Papyrus compilation were not run locally; use the included GitHub Actions workflow.
